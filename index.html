Pan/zoom to any city, then “Load streets in view”. For large areas tick “Main roads only”. Best run from a hosted URL (e.g. GitHub Pages) — live fetching is blocked when opening the file directly on a phone.
Why 21 Jun ≠ 21 Dec. You'd expect the two solstices to be mirror images, but atmospheric refraction bends the sun near the horizon, shifting the rising/setting direction. The street orientations the two solstices pick out therefore differ by about 2°, so a street that lines up with the December sun can sit a couple of degrees off the June sun, and vice versa.
Sun azimuths via an embedded solar-position routine (USNO low-precision). Street data © OpenStreetMap contributors, fetched live via Overpass.
